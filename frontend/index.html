Pontuação ESG

Acompanhe os resultados e as evidências de cada projeto financiado.

Como calculamos a nota?

Cada dimensão tem o mesmo peso e reúne dois indicadores. Para as metas demonstradas: 0 se o resultado registrado for zero, 50 se houver avanço abaixo da meta e 100 se a meta for atingida. Um indicador sem evidência fica Não avaliado.

A nota geral é a média das três dimensões, arredondada para exibição, e só aparece quando os seis indicadores podem ser avaliados. As metas são próprias de cada projeto. O financiamento comprova contratação; por si só, não pontua governança.
